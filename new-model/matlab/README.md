# 2025 数模 A 题「烟幕干扰弹的投放策略」MATLAB 代码

代码严格按《烟幕干扰弹投放策略——整合优化建模.md》的建模细节实现，数值格式与范例论文（刘灿等，《数学建模及其应用》2026, 15(1): 65-74）的表 1/2/3 一致。

## 文件结构

| 文件 | 说明 |
|---|---|
| `params.m` | 共享参数与场景数据（符号与建模文档 §1.1 一致） |
| `sample_target.m` | 真目标圆柱采样（单弹: 上下底圆周各 300 点；多弹: 5 层 × 50 点） |
| `missile_pos.m` / `uav_pos.m` / `bomb_pts.m` | 运动学模型（式 (1)–(4)） |
| `seg_sphere.m` | 线段–球相交解析判定（式 (7) 判别式形式） |
| `bool_cover.m` | 遮蔽状态布尔函数 Bool(t)（完全遮蔽准则） |
| `cover_intervals.m` | 粗扫 + 二分法求遮蔽区间（ε = 1e-5 s） |
| `union_measure.m` / `intersect_measure.m` | 区间并集测度（Q3/Q4）与交集测度（Q5 的 \|T1∩T2∩T3\|） |
| `eval_clouds.m` | 给定云团集合下某导弹的总遮蔽时长 |
| `predict_intercept.m` | 预测拦截点解析初始解（§7.2） |
| `de_optimize.m` | 差分进化（NP=100, Gmax=500, F=0.5, CR=0.9, 拒绝采样初始化 + 约束违反度 + 可行性规则选择） |
| `cons_Q2.m` / `cons_Q3.m` | 约束违反度 Φ（含烟幕高度约束 1(Z_smoke<10)） |
| `solve_Q1.m` … `solve_Q5.m` | 五问求解脚本（各输出论文格式表格） |
| `export_table.m` | 写出 result1/2/3.xlsx |
| `run_all.m` | 一键运行五问 |

## 运行方式

```matlab
cd new-model/matlab
run_all(true)    % 快速自检（约 5-10 min，验证逻辑）
run_all(false)   % 完整求解（论文参数，约 1 h，见各脚本头部说明）
solve_Q1         % 单问运行：约 1 s，应复现论文 1.391643 s
```

## 输出

- 控制台：与论文表 1/2/3 同格式的投放策略与效能表格
- `result1.xlsx`（问题 3）、`result2.xlsx`（问题 4）、`result3.xlsx`（问题 5），列格式与题目模板一致

## 说明

- 问题 1 的确定性结果应精确复现论文（8.056445–9.448088 s，1.391643 s），可作为代码正确性的自检基准。
- 问题 3/4/5 为优化问题，结果与论文数值可有小幅差异（随机初始化、网格划分不同所致），数量级与格式一致。
- 问题 4/5 的搜索采用「预测拦截点初始解 + 全局粗网格 + 邻域精细网格」设计：论文自述的"拦截点邻域局部网格搜索"无法到达其自身报告的最优解（如 FY3 拦截点最小可行时刻约 61 s，而论文报告解在 32–35 s，见建模文档附录 B），故代码以拦截点解为候选之一，再做 (θ, v, t_d, Δt_b) 全域粗网格扫描，并对最优候选做邻域精细网格。
- 问题 3 的 DE 初始种群除拒绝采样外，注入链式投弹与预测拦截点引导种子，帮助脱离"仅首弹有效"的适应度平台（8 维空间中多弹同时有效的解为窄尖峰）；DE 的变异/交叉/可行性规则选择规格不变（仍为论文 Step1–5）。快速模式即可复现论文 6.403 s 量级结果。
- 问题 5 的任务分配按建模文档式 (17)(18) 的 max-min ILP 实现；论文报告的分配（FY1,FY5→M1 等）在 c_ij 指标下与其他分配并列最优，属启发式综合结果，见建模文档附录 B。
