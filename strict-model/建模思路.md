## 1. 问题重述

无人机挂载烟幕干扰弹巡飞，受领任务后在来袭空地导弹与真目标之间投放烟幕，形成遮蔽，使导弹无法发现真目标。

- **真目标**：半径 7 m、高 10 m 的竖直圆柱，下底面圆心 `(0, 200, 0)`。
- **假目标**：坐标原点 `(0,0,0)`，导弹沿直线飞向它。
- **来袭导弹**：空地导弹，速度 300 m/s，飞行方向直指假目标。
- **无人机**：受领任务后瞬时调整航向，以 70~140 m/s **等高度**匀速直线飞行；每架至多投放 3 枚弹，两枚投放间隔 ≥ 1 s。
- **烟幕干扰弹**：脱离无人机后在重力下运动；起爆后瞬时形成半径 10 m 的球状烟幕，以 3 m/s 匀速下沉，起爆后 20 s 内有效。
- **任务**：设计无人机航向/速度、投放点、起爆点，使真目标被有效遮蔽的总时长尽可能长（多弹遮蔽可不连续）。

初始位置：

|---|---|---|---|
| M1 | (20000, 0, 2000) | FY1 | (17800, 0, 1800) |
| M2 | (19000, 600, 2100) | FY2 | (12000, 1400, 1400) |
| M3 | (18000, −600, 1900) | FY3 | (6000, −3000, 700) |
| | | FY4 | (11000, 2000, 1800) |

## 2. 建模假设（已确认）

1. **遮蔽 = 视线遮挡**：烟幕球为半径 10 m 的不透明区域，挡住"导弹→真目标"视线即遮蔽。
2. **严格完全遮蔽**：导弹必须看不到圆柱上**任何一点**（官方完整外轮廓判据）。
3. **探测纯几何、全程无限制**：导弹在任意距离、任意方向都能"看见"未被遮挡的真目标。
4. **多球合力遮蔽**：多枚弹的烟幕球**并集**共同遮挡，判定"每条视线都被至少一个球挡住"。
5. **弹道为平抛**：水平初速 = 无人机水平速度，竖直自由落体 g = 9.8 m/s²，无空气阻力。
6. **导弹匀速直线**：300 m/s 沿初始位置指向原点，直到命中（约 60~67 s）。
7. **烟幕硬截止**：起爆后 20 s 内有效，之后失效；球心匀速下沉 3 m/s。
8. **无人机定参**：航向/速度一经确定不变；引信延迟 Δt ≥ 0 且起爆点 z ≥ 0。
9. **目标函数（单导弹）**：最大化完全遮蔽总时长 = 各遮蔽时段的**并集**。

## 3. 数学模型

### 3.1 符号

- 时间 `t`（`t=0` 雷达发现时刻）；重力 `g = 9.8 m/s²`；烟幕球半径 `R = 10 m`。
- 真目标圆柱 `Ω = { (x,y,z) : x² + (y−200)² ≤ 7², 0 ≤ z ≤ 10 }`，轴线 `(0,200,z), z∈[0,10]`；底圆/顶圆圆心 `A_0=(0,200,0)`、`A_10=(0,200,10)`，半径 `r=7`。
- 导弹 `k` 初始 `P_k`，速度 `v_m = 300 m/s`；无人机 `i` 初始 `(x_i,y_i,z_i)`。

### 3.2 导弹运动

$$
M_k(t) = P_k + 300\,t\,\hat u_k,\qquad \hat u_k = -\frac{P_k}{|P_k|},\quad T_k^{hit} = |P_k|/300
$$

### 3.3 无人机运动

$$
D_i(t) = \big(x_i + v_i\cos\theta_i\,t,\ \; y_i + v_i\sin\theta_i\,t,\ \; z_i\big),\quad \theta_i\in[0,360°),\ v_i\in[70,140]
$$

（航向以 +x 轴为 0，逆时针为正。）

### 3.4 烟幕弹弹道

无人机 `i` 在 `t_r` 投放、引信延迟 `Δt`、起爆时刻 `t_d = t_r + Δt`：

$$
E_i = \big(x_i + v_i\cos\theta_i\,t_d,\ \; y_i + v_i\sin\theta_i\,t_d,\ \; z_i - \tfrac12 g\,\Delta t^2\big)
$$

### 3.5 烟幕云团

$$
C(t) = E_i + (0,0,-3)(t - t_d),\qquad t \in [t_d,\; t_d+20],\quad B(t) = \{ P : |P-C(t)| \le 10 \}
$$

### 3.6 完全遮蔽判定（核心）

**定义**：时刻 t，导弹 M 对目标 Ω 完全遮蔽 ⟺ 对任意 `Q∈Ω`，存在球 `j` 使线段 `[M,Q] ∩ B_j ≠ ∅`。

**线段-球相交判据**（点 C 到线段 [A,B] 距离 ≤ R，三分支、无奇点）：

```
v = B - A;  w = C - A;  c2 = v·v
若 c2 <= 0:      d2 = w·w            # A 与 B 重合
若 w·v <= 0:     d2 = w·w            # 垂足在 A 之前 → 最近点 A
若 w·v >= c2:    d2 = (w-v)·(w-v)    # 垂足在 B 之后 → 最近点 B
否则:            d2 = w·w - (w·v)²/c2 # 垂足在线段内部
返回 d2 <= R²
```

**定理 A（单球凸性）**：单球阴影区 `U(B) = { P : [M,P]∩B ≠ ∅ }` 是**凸集**，故
$$
\Omega \subseteq U(B) \iff C_0 \subseteq U(B)\ \text{且}\ C_{10} \subseteq U(B),
$$
其中 `C_0, C_{10}` 是上下两个边界圆环。即**单球只需检验两个圆环，无需采样圆柱内部或侧壁**（Krein–Milman：Ω 是两圆环的凸包）。

**定理 B（边界 ⟺ 整体）**：对任意球族，
$$
\Omega\ \text{被完全遮挡} \iff \partial\Omega\ \text{上每个点都被某球遮挡}.
$$
即多球只需采样表面 `∂Ω = 侧壁 + 上下两圆盘`，数学上严格，不必采内部点。

**多球判定（并集，不可约化为逐球）**：对表面采样点集 `{Q_l}`，时刻 t 完全遮蔽 ⟺

$$
\forall Q_l,\ \exists j:\ \mathrm{dist}\big(C_j(t),\, [M(t), Q_l]\big) \le 10.
$$

**采样与误差**（Lipschitz 界给出可证明的误差）：
- 单球：两个圆环各 `N` 点即可；`N=48` 已数值收敛（24→192 结果不变），保守取 `N=360`（弧间距 0.122 m）。
- 多球：侧壁在 `K+1` 个高度（`K=8~12`）各 `N` 点 + 上下圆盘内部（半径 r/2 与圆心）各若干点。
- 误差界：点-线段距离沿圆环是 r-Lipschitz，最大值估计误差 `≤ πr/N`；`N=360 ⇒ 0.061 m ≪ R=10`，足够精确。

**退化情形**：`M` 在某球内（`|M−C_j|≤R`）⇒ 直接完全遮蔽；球在视点后方/太远 ⇒ 判据自然返回 False（无需特判）；`d→R⁺` 时锥式分母趋零、但线段-球判据无奇点，故**始终用线段-球判据**。

### 3.7 有效遮蔽时长与目标函数

$$
T_k = \big|\{ t : \text{时刻 }t\text{ 对目标完全遮蔽}\}\big| \quad(\text{多区间取并集})
$$

- **问题 1~4**：`max T_1`。
- **问题 5**：三套目标各算一遍——(a) `max Σ_k T_k`；(b) `max min_k T_k`；(c) `max |{t : 三导弹同时完全遮蔽}|`。

## 4. 各问题求解思路

### 4.0 统一目标函数管线（各题复用）

- **圆柱采样点**：单球用两圆环（定理 A），多球用表面采样（定理 B）；点数 `N_p≈40~60` 剪影采样即可近似，加 ~10 个上下底内部点兜底。
- **导弹轨迹/采样点/起航线**：与决策变量无关，预计算一次缓存。
- **单次求值**：对每个活跃云球（`τ_b ≤ t ≤ τ_b+20`）逐采样点算点-线段距离，`dist ≤ 10` 即被遮；完全遮蔽 = 所有采样点都被**至少一个**球遮住；`T = dt·Σ_t I(t)`（0/1 并集）。
- **加速**：剪影采样降点、活跃云提前剪枝 + 短路、自适应 `dt`（粗扫定位非零区间后二分精修边界）、常量缓存、多进程并行。

### 4.1 问题 1（给定参数，直接计算）

`θ=180°`、`v=120`、`t_r=1.5 s`、`Δt=3.6 s`，按 §3 计算，`dt=0.0005` 扫描累加。**结果见 §6**。

### 4.2 问题 2（FY1 单弹，4 维）

编码 `x∈[0,1]⁴` → `θ∈[0,360)`、`v∈[70,140]`、`t_r∈[0, T_max]`、`Δt∈[0, √(2h/g)]`。

- **主算法**：差分进化 DE（`popsize=15×4=60`，`maxiter≈250`，约 1.5 万次求值），初代混入 LHS 2000 点保证含非零个体。
- **备用**：LHS 5000 点 → top-K 可行点 → Nelder-Mead 局部精修。

### 4.3 问题 3（FY1 投 3 弹，8 维）

**间隙编码**（天然满足排序与 ≥1 s 间隔）：`x = [θ, v, t_r⁽¹⁾, Δt₁, g₂, Δt₂, g₃, Δt₃]`，其中 `g₂,g₃ ≥ 1`，推出 `t_r⁽²⁾=t_r⁽¹⁾+g₂`、`t_r⁽³⁾=t_r⁽¹⁾+g₂+g₃`。约束全部变成盒子约束。

- **主算法**：DE（`popsize=100`，`maxiter≈350`，约 3 万次求值）。

### 4.4 问题 4（3 机各 1 弹，12 维）

编码分块 `[θ_j,v_j,t_r⁽ʲ⁾,Δt_j]` 顺序拼接（纯盒子约束）。

- **主算法**：DE（`popsize=120`，`maxiter≈400`，约 5 万次求值）。
- **备用**：CCDE 协同进化（按无人机分 3 组件）或 LHS 2 万 + NM。

### 4.5 问题 5（5 机 ×≤3 弹 vs 3 导弹，混合整数）

**分层：外层离散分配（GA）+ 内层连续优化（DE）**。注意 `θ,v` 是**每机**的，`t_r,Δt` 与目标分配是**每弹**的。

- 外层 GA 编码：每机 `n_j ∈ {0,1,2,3}`（发几弹）+ 每弹 `a∈{1,2,3}`（打哪枚导弹）。
- 内层对每枚导弹独立 DE（同 Q2~Q4）。

三种目标的结构差异：

- **(a) `max Σ T_k`：可精确分解**。不同导弹云团互不共享，故 `max Σ T_k = Σ_k max T_k`——外层只分配，内层三导弹独立 DE，外层适应度 `= Σ T_k*`。强烈推荐，三导弹内层可并行。
- **(b) `max min T_k`**：外层 GA 分配 + 内层独立 DE 返回 `(T₁,T₂,T₃)`，适应度 `= min`；外层进化把弹数向最弱导弹倾斜。（可用 (a) 热启动。）
- **(c) 同时遮蔽 `max S`**：时间耦合，最难。两阶段：先对每枚导弹找"可遮蔽窗口模板"，再选相位对齐三窗口使交集最大；实现上用外层 GA 分配 + 内层**联合 DE**（目标 = 同时遮蔽时长），辅以 CCDE 按导弹分组件。预算最高。

## 5. 优化通用技巧（关键，不做好其余都次要）

1. **破 0 平台（最致命）**：真目标 `T` 几乎处处 0，直接优化必停滞。改用**代理适应度**：
   - 点级裕量 `d_m(t) = R − min_j dist(C_j(t), [M(t)P_m])`；
   - 遮挡率 `f(t) = mean_m[d_m>0]`，最坏裕量 `m(t) = min_m d_m(t)`（`m>0 ⟺ 完全遮蔽`）；
   - 平滑得分 `F = Σ_t f(t)dt`，深度裕量 `M = Σ_t max(0,m(t))dt`；
   - **`fit = T + ε·F + α·M`**（ε,α 取小量）。在 0 平台给"爬向可行域"的坡度，在等 T 处推向"遮得更深"的中心。**最终报告用真 `T`，不用代理值。**
2. **遮蔽窗口极窄（Q1 仅 1.4 s）**：可行域是极薄壳层，用深度裕量 `αM` 把解推向中心；`dt=0.01` 使 1.4 s 有 ~140 个台阶可排序；边界用二分求精确。
3. **`Δt` 窄带**：云须落在圆柱高度带，`Δt` 收窄到对应 `z_det∈[0,40]` 的 `[Δt_lo, Δt_hi]`，省一半无效搜索。
4. **水平漂移**：`v·Δt` 可达数百米，`t_r` 上界放宽（`T_max ≥ 20 s`）。
5. **多球判据别写错**：是"每个圆柱点都要被至少一个球遮住"，不是"球并集盖住质心"。

### 算法横向对比

| 算法 | 非光滑/平台 | 多峰 | 维度上限 | 混合整数 | 适用 |
|---|---|---|---|---|---|
| DE | 好 | 好 | ≤~15 | 需改造 | Q2~Q4 主、Q5 内层主 |
| CCDE 协同 | 好 | 好 | 40+ | 否 | Q4/Q5(c) 备 |
| GA(SBX+整数) | 中 | 中 | 中 | **天然支持** | Q5 外层分配 |
| PSO | 平台易停滞 | 中 | 中 | 否 | 备用 |
| LHS+NM | 仅播种/精修 | 差 | 低 | 否 | 初始化/微调 |

## 6. 模型验证（问题 1 锚点）

| 判据 | 遮蔽时长 | 遮蔽区间 |
|---|---|---|
| 点目标（轴中点 (0,200,5)） | 1.4055 s | [8.0135, 9.4185] |
| 完整圆柱（本模型判据） | 1.3920 s | [8.0565, 9.4480] |

- 点目标 **1.4055 s** 与已发表 benchmark **完全一致** → 弹道/导弹/视线几何正确。
- 完整圆柱 **1.3920 s** 与独立计算完全一致，且对采样密度收敛（24→192 点不变）。
- 物理解释：起爆点距导弹约 275 m（导弹 t≈8.5 s 时 x≈17463，起爆 x=17188），10 m 球在 275 m 处张角 0.036 rad，远大于圆柱视半径 7 m/17600 m ≈ 0.0004 rad（约 80 倍），故单弹足以遮蔽整个圆柱视盘。**严格判据可行、不退化。**
